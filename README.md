# Imagina Menu

Navegación móvil tipo app para WordPress y WooCommerce: panel lateral con submenús deslizantes, modo de dos columnas con imágenes, barra de navegación inferior y buscador, con un presupuesto de rendimiento estricto (sin jQuery, HTML renderizado en el servidor y CLS = 0).
