# Imagina Menu — versiones para instalar

Esta rama solo contiene el plugin empaquetado, listo para instalar en WordPress (sin código fuente).

**Última versión: 0.5.7** — [descargar imagina-menu.zip](https://github.com/augusto97/imagina-menu/raw/release/imagina-menu.zip)

## Instalar

1. Descarga el ZIP de la versión que quieras.
2. En WordPress: **Plugins → Añadir nuevo → Subir plugin**, elige el ZIP y actívalo.
   Para actualizar sobre una versión instalada, WordPress ofrece «Reemplazar la versión actual».
3. Con Imagina Updater: sube el mismo ZIP al servidor de actualizaciones.

Verifica la descarga con `sha256sum -c SHA256SUMS` (ver [SHA256SUMS](SHA256SUMS)).
